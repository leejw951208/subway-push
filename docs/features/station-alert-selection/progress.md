## 블로커 / 이슈 / 특이사항

- 기기 위치 권한 요청 코드는 발견되지 않았다.
- 알림 권한 요청은 알림 표시 기능에 필요한 별도 범위로 유지한다.
- `SubwayAlert.station`은 현재 선택한 목적 역, 즉 내릴 역으로 사용된다.
- `SubwayAlert.timing`을 추가해 `도착할 때`, `1정거장 전`, `2정거장 전` 중 하나를 저장한다.
- API DTO와 Prisma `Alert.timing`을 추가해 서버 알림 경로에서도 알림 시점을 보존한다.
- 제품 문구는 `내릴 역`을 선택 대상으로 쓰고, 알림은 방식과 시점 옵션으로 분리한다.
- iPhone 17 시뮬레이터에서 홈 화면의 `내릴 역을 선택하세요` 문구와 `추천` 칩을 확인했다.
