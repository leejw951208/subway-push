# Plan. Station Alert Selection

## 단계 구성

| Phase | 이름        | 목표                                   |
| ----- | ----------- | -------------------------------------- |
| P1    | 방향 정리 | 위치 권한 기반 계획을 제거하고 직접 역 선택 기반 UX를 기준으로 삼는다 |
| P2    | UI/문구 점검 | 앱에 위치 권한 전제 문구가 없는지 확인하고 역 선택 흐름을 명확히 한다 |
| P3    | 수동 탑승 확장 준비 | 후속 수동 탑승 모드가 기존 알림 모델과 충돌하지 않게 정리한다 |
| P4    | 검증 | 기존 알림 설정, 저장, API 연동 테스트가 유지되는지 확인한다 |

## 아키텍처 다이어그램

```
Station search / recommendation
  └─ selected Station
       └─ AlertSheet
            └─ SubwayAlert
                 ├─ local storage
                 └─ API alerts path

Future manual boarding mode
  └─ line + current station + direction + destination station
       └─ reuses destination Station
```

## 테스트 매트릭스

| #   | 케이스 | 입력 | 기대 결과 |
| --- | ------ | ---- | --------- |
| 1   | 역 선택 | 추천 역 또는 검색 결과 선택 | 알림 설정 시트 열림 |
| 2   | 알림 저장 | 역과 알림 옵션 | 내 알림 목록에 저장 |
| 3   | 기존 알림 수정 | 이미 알림 있는 역 선택 | 기존 설정 수정 |
| 4   | 위치 권한 없음 | 위치 권한 미요청 상태 | 역 선택 알림 흐름 정상 동작 |
| 5   | 알림 권한 거부 | 알림 권한 denied | 알림 설정은 유지하고 표시 제한 안내 |
