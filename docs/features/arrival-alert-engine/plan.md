## 아키텍처 다이어그램

```
Location source
  └─ ArrivalAlertEngine
       ├─ distance(current, station)
       ├─ threshold policy
       ├─ duplicate guard
       └─ AlertEvent(push/vibration/voice)
```

## 테스트 매트릭스

| #   | 케이스 | 입력 | 기대 결과 |
| --- | ------ | ---- | --------- |
| 1   | 역 근처 진입 | 거리 < threshold | 알림 이벤트 1개 |
| 2   | 역 밖 | 거리 > threshold | 이벤트 없음 |
| 3   | 중복 방지 | 이미 notified | 이벤트 없음 |
