# 위키 목차

## 목적

이 위키는 내릴때 프로젝트의 장기 기억이다. 코드를 변경하기 전에 읽으면 프로젝트 맥락, 기능 상태, 아키텍처, 알려진 주의점을 세션이 바뀌어도 일관되게 유지할 수 있다.

## 읽는 순서

1. `overview.md`
2. `architecture.md`
3. `features.md`
4. `decisions.md`
5. `mistakes.md`
6. 명령, 세팅, 마이그레이션, 배포가 필요하면 `runbook.md`를 읽는다.

## 문서 목록

| 파일 | 목적 |
|---|---|
| `overview.md` | 프로젝트 목적, 현재 상태, 핵심 범위, 제외 범위. |
| `architecture.md` | 시스템 구조, 모듈 책임, 데이터 흐름. |
| `features.md` | 기능별 동작, 구현 상태, 관련 파일. |
| `decisions.md` | 프로젝트 결정, 이유, 영향. |
| `runbook.md` | 로컬 세팅, 실행, 테스트, DB, 문제 해결 절차. |
| `mistakes.md` | 이후 작업에서 피해야 할 반복 실수와 해결책. |
