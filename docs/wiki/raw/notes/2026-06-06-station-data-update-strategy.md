# 지하철 역 데이터 최신화 방식

## 날짜

2026-06-06

## 맥락

지하철 역 최신 업데이트를 어떻게 운영하면 좋을지 논의했고, 여러 대안 중 공식 데이터 파일을 주기적으로 가져와 코드 생성하는 방식을 선택했다.

## 원본 내용

선택한 방식은 “공식 데이터 원천을 가져와 단일 JSON으로 정규화하고, 그 JSON을 기준으로 API용 TypeScript 데이터와 모바일용 Dart 데이터를 생성하는 방식”이다.

운영 방향은 아래와 같다.

- 공식 데이터 원천을 사용한다.
- 수동 실행 스크립트로 데이터를 가져온다.
- 역명, 호선, 설명, 좌표, 외부 역 코드 등을 정규화한다.
- 중복 역과 환승역을 병합한다.
- 단일 JSON 원본을 만든다.
- TypeScript와 Dart 정적 데이터 파일은 생성물로 관리한다.
- 생성 후 diff를 사람이 검토하고 커밋한다.
